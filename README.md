# Samrat Studio Patna — Luxury Wedding & Fine Art Photography

> **Documentary & Fine Art Wedding Photography Collective based in Patna, Bihar.**  
> Capturing authentic intimacy, cultural rituals, and regal celebrations across India.

---

## 🌟 Features & Highlights

- **Bespoke Ken Burns Film Reel**: Dynamic animated showcase presenting flagship wedding stories with 3-second auto-transitions and mobile touch-swipe gestures.
- **Acoustic Soundscape Engine**: Web Audio API camera mechanical shutter releases (`playShutterSound`).
- **Proprietary Color Science Split-Viewer**: Interactive raw-sensor vs signature grade comparator slider with touch and drag support.
- **35mm Analog Negative Lightbox**: Fullscreen archival viewer with simulated analog contact stamps, EXIF optics metadata, and keyboard / touch-swipe navigation.
- **Responsive & Mobile-First**: Crafted to deliver an editorial experience across smartphone viewports (`100dvh` address bar handling), tablets, laptops, and 4K displays.
- **Disciplines & Investment**: In-depth breakdowns of Wedding Photography, Cinematic Films, Pre-Wedding Expeditions, and Bridal Fine Art portraiture.

---

## 🛠️ Technology Stack

- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: TailwindCSS & Vanilla CSS design system
- **Routing**: React Router v6
- **Icons**: Lucide React
- **Audio**: Web Audio API synthesized harmonics

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Swatantraraj19/Samrat_Studio.git
cd Samrat_Studio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
